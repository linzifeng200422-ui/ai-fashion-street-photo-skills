# Soul 风格选择库

在用户要选择 Soul 摄影风格、查看风格预览或比较预设时读取。已经明确选择的风格直接沿用，不重新开始选风格。

## 本地资料

- [本地图片总览](../assets/soul-style-library/index.html)：离线查看名称和官方样图，点击图片可查看本地原预览。
- [名称与预设索引](../assets/soul-style-library/catalog.json)：包含 `name`、`style_id`、相对图片路径、来源链接、获取日期、下载状态及图片核验信息。按名称或 ID 定位所需条目，不默认把整个目录加载到上下文。
- [源目录快照](../assets/soul-style-library/source-catalog.json)：保留 MCP 返回的目录数据，便于核对更新。
- 官方预览原文件位于 `assets/soul-style-library/previews/`，均为本地实际图片，不是只保存远程链接。

此库是 2026-10-22（Asia/Shanghai）从 Higgsfield MCP `get_presets(source="soul", limit=50)` 取得的 33 项目录快照，不代表以后数量不会变化。预览图来自目录返回的 Higgsfield 官方 CDN；保留原名、来源链接及实际文件，不将其署名为本技能作者作品或另行声明第三方图片的许可。

## 选择风格

1. 先读索引中的名称和本地图片路径，按用户描述筛选相关条目；实际查看相应样图后再概括摄影表现。
2. 给用户展示真实名称和官方样图，不把样图说成本次生成结果，也不把样图人物当作用户选定人物。用户可自行选定，也可明确授权助手代选。
3. 记录所选 `name`、`style_id` 和目录日期。风格和人物身份分别管理，同一预设可以用于不同人物。
4. 若需要更新或用户准备通过 MCP 执行，读取当前可用的 Higgsfield 工具说明，用 `get_presets` 的 Soul 来源核对所选条目；需要同步整个库时读取完整当前目录。目录有变动时下载新增或已变化的官方预览并更新索引；已有文件和已选条目记录不能因一次联网失败就删除。
5. MCP 不可用时，可以继续用本地样图讨论摄影方向，并说明这是带日期的缓存。不要宣称已经调用远端预设。

## 调用边界

- 浏览、下载与选择风格不等于授权生成图片。
- 当前 Soul 目录中条目的 `id` 对应 Soul 生成调用的 `style_id`，不是人物 `soul_id`。以执行时的工具说明为准。
- 当前 MCP 说明允许 Soul 风格和 Soul ID 组合，但不允许 `style_id` 与 `medias` 图片参考同时使用。不能因为本地有预览就绕过这项输入限制。
- 预览图是目录样本，不自动上传成生成参考。使用其他模型时，保留用户确认的摄影方向，并按那个工具实际支持的参考方式组织输入；不能把 Soul 预设 ID 直接当成其他模型的参数。
- 下载状态、文件可解码及来源对应关系才是缓存完成的依据。失败条目明确标记，不用其他风格的样图填补。
