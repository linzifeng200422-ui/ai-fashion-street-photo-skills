# 各阶段可复制提示词

适用于用户选择的生图或图像编辑工具，不需要特定软件或连接器。支持 Skill 的助手可以按本手册组织操作；普通网页工具也可复制相应提示词并提供图片。

方括号内容按实际需求替换后再发送。图片编号按本次实际附件排列；工具使用其他引用语法时相应转换。已有图片可直接引用的，不必重复上传。数量、画幅和风格按用户要求；示例不限制其他用法。

## 1. 选定人物

已有满意人物时跳过此步。风格人脸参考可选，商品图用于理解服装定位，不必把衣服模特的长相一并继承。

```text
请生成[数量]位不同长相的虚构成年模特候选，每位一张独立人像，画幅为[画幅]。

这次服装的风格是[服装风格]。人物气质、发型和外观方向为[人物要求]，适合展示这类衣服。候选之间有可辨认的长相差异，不只是把同一张脸换几个表情。

采用[已选摄影风格与光线]，取景为[景别]。如果附了风格参考，只借鉴我指定的部分；人物最终以我选中的候选为准。

皮肤、发束和衣料保留自然细节，避免不需要的磨皮、油亮高光、过度锐化和重复假纹理。

分别展示并标注候选，保留原图，供我选择。
```

### 摄影要求怎么填

这部分适用于**第1步选定主图和第2步丰富表情**，用来填写提示词中的摄影要求。把光从哪里来、哪些部位亮、阴影落在哪里说清楚，再补充需要的成像质感。下面两段是可选示例，按本次需求选用或调整；已有其他摄影风格时直接沿用，不叠加互相冲突的布光。

**示例一：CCD 直闪随拍**

```text
近距离小型数码相机的随拍质感，正面机顶直闪。额头、鼻梁与面颊有自然局部光泽和明暗过渡，其余皮肤保留正常肤色，避免连片过亮发白。下颌及身后稍暗的朴素背景有符合闪光方向的落影。保留自然发束、衣料细节和轻微数码噪点，不用全脸油光、磨皮、过度锐化或密集假细纹代替照片质感。
```

**示例二：柔和窗边自然光**

```text
柔和的日间窗光从画面左前上方照向人物。靠窗一侧的额头、颧骨与鼻梁自然受光，另一侧面颊逐渐转暗，鼻子和下颌产生向右下方延伸的柔和阴影。亮部保留肤色层次，暗部仍能看清五官结构，人物与背景有适度明暗差。保留皮肤自然色差、发束与衣料细节，不把全脸提白或磨平，呈现自然的人像照片质感。
```

选中后可发送：

```text
选这张作为后续人物主图，保留原图或当前可用的图片引用，后续以它作为身份参考。不继续生成候选。
```

## 2. 丰富表情与角度

**图片**：主图作为人物参考；需要时另加一张摄影参考，并说清它只负责摄影表现。

```text
以这张已选主图为人物身份参考，生成[数量]张同一人的自然表情近景，画幅为[画幅]。

保留主图人物的五官、年龄感、发型及我确认的外观。表情、目光与头部朝向按[所需表情或角度]变化；未指定具体动作时，像朋友交谈中抓拍的自然瞬间，眼神、眉毛、嘴角和头肩随情绪联动。

各张独立参考同一张主图，不默认用上一张新结果继续衍生。视角和表情应满足本次需要，避免所有结果无意中重复同一姿态。

本次需要多角度参考时，覆盖将要使用的不同侧面，让转头、低头或看画外等状态自然变化，不要整组都同侧仰头或死盯镜头。仅需单一角度时，按指定角度生成。

摄影采用[本次确认的摄影方式与光线]；未另指定时延续主图的摄影表现。若另附摄影参考，只参考指定的光线和成像质感，不继承其中人物的长相。

输出独立原图，依次展示给我选择。
```

摄影要求可直接选用或调整[第一步的摄影示例](#摄影要求怎么填)，不必为每张表情另换一套光线。

### 可选：双参考完整提示词

需要对齐某张照片的摄影效果时使用这一分支；直接采用主图的摄影表现或文字布光要求时，使用前面的单图方式即可。摄影参考可以是直闪、自然光或本次选定的其他风格。

**附图**：图1＝已选人物主图；图2＝摄影参考图。若图2是拼版，说明要参考其中哪一张，或先裁出那张照片。

```text
请以图1为人物身份参考、图2为摄影参考，生成[数量]张同一人的自然表情近景，画幅为[画幅]。

图1负责人物身份：保持同一个人的脸型、五官关系、年龄感、发型及我已确认的外观。表情与头部朝向可以按本次要求自然变化，不把保持身份理解成固定住原来的神情与姿势。

图2只负责摄影表现：参考其中[指定照片或区域；单张照片可写“整张照片”]的主光方向、光线软硬、亮部与落影关系，以及我希望保留的成像质感。不继承图2人物的长相、发型、服装或姿势，不带入其中的文字、画框和拼版排布。

让图1这个人呈现[本次需要的自然反应、表情或角度]，像交谈中被抓拍的瞬间。眼神、眉毛、面颊和嘴角随情绪自然联动，头肩放松；每张表达一个连贯状态。重新表现人物在所选光线下的自然反应，不只是给原图叠一层滤镜。

各张都独立以图1为人物身份依据，不用上一张新结果继续衍生。布光参考图2，亮部保留肤色和明暗过渡，阴影与受光方向相符。皮肤、发束与衣料各有自然质感，不把同一种密集细纹铺满所有表面，也不用过度磨皮、锐化、重颗粒或模糊遮掩问题。

输出独立照片，不做拼图，不加文字或水印，依次展示供我核对人物、表情与摄影效果。
```

### 表情怎么描述、生成后怎么选

需要具体描述某种表情时，可以写“正在发生的反应＋面部联动”，不用只写“开心”，也不用为每个部位规定精确动作。例如：

```text
像听到朋友一句有趣的话，正在努力忍住笑：嘴角微微扬起，面颊和眼睛自然产生笑意，头颈放松，保留轻微不对称的变化。
```

这只是单张表情的描述示例，不要求整组都忍笑。按本次需求选择自然反应，不把互相冲突的情绪塞进同一张图。

生成后逐张对照主图，再检查整组：

1. **是不是同一个人**：看脸型、五官关系和已确认的外观是否一致；表情带来的嘴角、脸颊变化不等于换了人。
2. **表情是否生动**：眼神、眉毛、脸颊和嘴角是否随情绪自然联动，有没有僵硬假笑或明显的嘴眼变形。
3. **所需侧面是否齐全**：需要多角度复用时，检查是否有本次要用的不同侧面、转头方向，且面部清晰可辨；不要把全是同一侧的图当成完整的多角度参考。只需要一种角度时，不额外补齐所有角度。

把合格图片与主图一起整理；不足的角度或不自然的表情单独补做，不必推翻整组。

### 可选：转头方向纠偏

当结果反复同侧、总是仰头，或本次明确要求换边时使用。下面以补1张向画面右侧转头的照片为例，方向、视线落点、数量和画幅按实际要求调整；不用把这段固定加入每张表情图。

**附图**：图1＝已选人物主图。若同时使用摄影参考，可沿用当前可访问的引用，或另附图2，并按上面的双参考分工指定用途。

```text
以图1为人物身份参考，重新生成1张自然表情近景，画幅沿用主图。

保持同一个人的长相、年龄感、发型与已确认的外观。这次鼻尖明确朝画面右侧，目光看向右侧画外，下巴自然放松，不后仰。

表情沿用本次已经选定的自然反应，让眼神、眉毛、面颊与嘴角随情绪联动，头颈放松，不为转头把脸摆成僵硬的固定表情。

摄影沿用本次已经确认的光线与成像质感；若附了图2，它只提供摄影参考，不提供人物长相。肤色与阴影自然，保留未要求改变的其他外观。

输出1张独立照片供我核对转头方向、视线与人物长相，不做拼图。
```

### 可选：已有主图的光感校准

适用于已经选好人物，只想调整光感或肤质的情况。

```text
以这张主图为人物参考，只调整[需要修正的光感或肤质问题]，先生成[数量]张供我对照。

保留人物长相、发型、头部角度与当前表情，采用[已确认的摄影光线]。只修我指出的问题，不额外改变其他外观。

例如本次问题若是直闪导致额头、鼻梁连片过亮，就改善亮部层次与肤色过渡，保留合理落影；不要用整脸磨平或提白来遮盖问题。
```

## 3. 整理人物参考

“人物1”只是便于交流的名称，可以换成用户自己的命名。

**普通图片方式：**

```text
把我选中的主图和这些合格表情图归为同一个“人物1”参考集合，标明哪张是主要身份参考、哪些补充侧面或表情。保留原图及可用的图片引用。

后续生成时，使用当前工具实际可访问的主图和所需补充图；不要把只写“人物1”这个名字当成已经输入了参考图片。此步只整理，不生成新图。
```

**工具自带角色库时，可选：**

```text
如果当前工具支持角色保存或人物引用，请将我确认的这些图片关联到选定的人物，主图作为主要参考，其余作为补充。已有对应人物就沿用，不重复建立。

回报实际保存或关联的结果。没有这个功能，就保留图片参考方式，不需要为了继续出图创建角色库。此步不生成新图。
```

## 4. 选择单张底图

可以使用自己的实拍图、已有生成图或有权使用的参考图片。已有底图时跳过挑选；配套图库是可选资源。

```text
从这组街拍参考中挑选[数量]张适合展示本次服装的底图，说明选择理由。优先考虑衣服能否看清、姿势与构图是否合适、现场光线是否符合需求。

人物身份沿用我已选定的人，服装款式以商品图为准，图库仅提供拍摄底图。如果原文件是拼版，裁出所选的单张照片，不把整个拼版当作一张底图送去编辑。

此步只选图和整理，不生成新图片。使用配套街拍图库 Skill 时进入挑选模式，不自动扩写一批新场景。
```

## 5. 换脸与换装

### 5.1 普通参考图片方案

可用于没有角色库、但支持相应图像参考或编辑的工具。

**基本附图**：图1＝底图；图2＝人物主图；图3＝商品图。

**按需增加**：上下装两件套可再附下装图；侧脸需要补充依据时可再附角度参考。增加图片后，在消息开头逐张写清用途，按实际输入重新编号。

```text
请编辑图1，生成[数量]张[画幅]的服装展示图。

本次图片分工：图1是拍摄底图；图2是目标人物主图；图3是要展示的[商品类型]。[如有其他图片，在这里逐张注明用途。]

人物按图2的五官与我选定的外观替换。尽量保留底图的头部位置、朝向、身体姿势与比例，让脸、头发、耳朵和颈部自然衔接。人物受光、阴影和色温跟随图1，不搬入人物参考中的背景或另一套布光。

服装按商品图的款式、颜色、版型和可见细节替换。只更换这次要求的衣物，未要求修改的衣物、鞋和配饰保留原图；连衣裙按其实际覆盖范围替换。衣褶、遮挡与接触阴影符合底图姿态及现场光线，不添加商品图里没有的设计。

保留底图构图、环境和自然动作，输出独立成图供我与商品原图对照。底图已经是目标人物时，不必再改脸。
```

#### 上装＋下装两件套：完整示例

**附图**：图1＝底图；图2＝人物主图；图3＝上装商品图；图4＝下装商品图。下面以生成1张、沿用底图画幅为例，数量和画幅按实际需求调整。

```text
请编辑图1，生成1张服装展示图，画幅沿用图1。

图片分工：图1是拍摄底图，图2是目标人物主图，图3是上装商品图，图4是下装商品图。

人物按图2的长相和已确认的外观替换，保留图1的头部朝向、身体姿势与比例，让脸、头发和颈部自然衔接。人物受光、阴影和色温服从图1的现场光线，不搬入图2的背景或布光。底图已经是目标人物时，保留原人物。

上装替换为图3所示款式，颜色、版型、领口、门襟及可见细节按图3；下装替换为图4所示款式，颜色、腰部结构、轮廓及可见细节按图4。两件商品分别对应，不把上装的图案或材质套到下装，也不遗漏下装替换。不添加商品图里没有的设计。

两件衣物的穿着关系、衣褶、遮挡和接触阴影适应图1的姿态与现场光线。保留底图构图、环境、自然动作，以及未要求更换的鞋和配饰。

输出独立成图，供我分别对照人物主图、上装和下装商品图核验。
```

### 5.2 已选角色引用方案（可选）

仅在当前工具确实支持并且已经选定该人物时使用。

**附图**：图1＝底图；图2＝商品图；人物使用平台实际选定的角色或人物引用。套装的下装图按实际附件另标编号。

```text
使用当前工具中我已选定的[人物引用]及其有效参考，编辑图1，换上图2所示的[商品类型]，生成[数量]张。

人物保持已选参考的长相与外观；底图已是该人物时不再改脸。动作、构图、背景与现场光线沿用图1，换入人物的受光与场景统一。

服装的款式、颜色、版型和可见细节以商品图为准，只换指定衣物，其余衣物、鞋与配饰不重新设计。完成后展示结果供我核对。
```

角色引用不能实际访问时，说明问题并改用用户提供的人物图片参考；不要假称已识别某个角色。若工具本身不支持所需参考或编辑操作，说明该步骤的实际限制，再讨论受支持的方案，不虚构功能。

### 5.3 旧图复用或只换衣服

旧实拍图可以直接用作底图，不需要先生成新场景。需要换人物时使用5.1或5.2；只换衣服时可直接发送：

```text
只把底图中[需要替换的衣物]换成商品图所示款式，生成[数量]张。

人物长相、发型、表情和姿势保持原图，未指定的其他衣物、鞋和配饰不动。商品颜色、剪裁与可见细节按商品图，衣褶和光影适应底图，背景和构图保留。
```

## 6. 核对与局部修整

对照人物与商品参考，检查长相、款式、颜色、文字字体、边缘衔接和光影。问题描述具体到位置与差异；有局部编辑或蒙版功能时可使用，不能假设每个工具都提供同样的操作。

```text
图1为待修结果，图2为对应的商品或人物参考。请只修正[具体位置与错误]。

按图2恢复该处的[款式、颜色、文字字形或其他细节]，保持未指定区域尽量不变，光线仍服从原场景。展示修前修后同一位置供我核对，不重新设计整套穿搭。
```

## 7. 上新复用

保存选定人物参考、底图、有效提示词和工具中可用的引用。下次只更新商品与确实需要改变的要求，不默认重做选人和表情。

```text
沿用已经选定的人物参考和这张底图，换上我这次提供的新商品，生成[数量]张供我检查。人物与场景保持原有设定，只调整新商品所需的穿着与光影衔接。
```

如果当前工具无法继续访问之前的图片，重新提供对应图片即可，不必重新生成一个人物。需要沉淀工作流时保存实际有效的方法与素材分工；能否直接保存为 Skill 或角色资源，按所用工具的实际功能处理。
