# Soul 2.0 自然街拍提示词 | 图片安装版

本 Skill 的唯一可视数据源是 `assets/01_assets_01-08.png` 至 `assets/06_assets_41-48.png`。六张图共包含连续编号 `01—48` 的用户自生成街拍母图。不要联网寻找人物参考，不要加入包外造型，不要把用户附件自动保存进 Skill。

## 启动与挑选

- 用户只启动 Skill、说“简易模式”或没有提 Soul ID：进入模式 A，不带 Soul ID，直接从六张 assets 中选择 8 个差异明显的方向，输出 8 条完整 Prompt。
- 用户说“挑选模式”“看模板”“调出母图”：按页码顺序展示六张 assets，并说明可以输入 `5`、`25`、`31模特在36环境` 或 `脸1＋环境3＋穿搭8`。
- 单独输入 `1—48`：定位包含该编号的 asset，实际查看对应照片；先输出 `00｜母图复现提示词（由成图反推）`，再输出 A—H 八条同系延伸。不得把反推词冒充原始生成词。
- 用户说“1好看”“沿着1继续”：立即进入该编号的 `00＋A—H`，不要重新随机八个方向。
- 用户说“就用这个”：停止分支，只给一条完整中文与语义对齐的英文精修长版。

## 两种人物模式

### 模式 A | 不带 Soul ID

- 设置：`Soul 2.0 | Soul ID / CHARACTER 关闭 | 画幅建议 3:4`。
- 人物默认是二十多岁的东亚成年女性。根据所选母图可见结果，具体写出脸型、杏仁眼与眉形、鼻唇比例、真实肤色、发型和妆感；“漂亮、高级”必须落实为可见结构，不写塑料皮、尖下巴或欧美深眼窝。
- 编号只锁审美类型，不承诺每次生成是同一身份。用户要求严格同一人时切换模式 B。

### 模式 B | 带 Soul ID

- 用户附人物图并说“带 Soul ID”“有 Soul ID 提示词”“锁这个人”时启动；设置为 `Soul ID / CHARACTER 开启并选择当前 Soul ID`。
- 实际查看 Soul ID 图片，反推一段　定外貌锚点：年龄呈现、脸型、眼眉鼻唇比例、肤色质感、发型和妆感。每条 Prompt 完整复用，不写 `the selected Soul ID remains recognizable` 等空泛句。
- Soul ID 独占身份；编号卡只能贡献穿搭、Pose、表情能量、注意力、道具、环境、机位、光线和媒介，不能换脸。
- 会话持续保持模式 B，直到用户明确关闭、取消锁人或发送新人物图并说更换 Soul ID。
- 模式 B 输入单编号仍输出 `00＋A—H`，只替换人物身份段，其余母图视觉关系不变。

## 母图反推

查看编号母图后，按可见事实依次提取：

1. 人物：年龄感、非身份化五官结构、肤色质感、发型与妆感。
2. 完整穿搭：上装、下装或连衣轮廓、外层、鞋、包、配饰、固定道具、材质、配色和褶皱。
3. 人物状态：正在发生的微事件、注意力对象、表情阶段、支撑脚或支撑面、髋肩扭转和每只手的任务。
4. 环境：地点类型、前中后景、道路标线、门窗、栏杆、台阶、家具、车辆、植被、天气和人流。
5. 相机：景别、距离、机位高度、俯仰、观察方向、焦段观感、透视与裁切。
6. 光色媒介：自然光、逆光或直闪关系，颜色层级、颗粒、数码锐化、运动边缘、局部过曝和白平衡偏差。

母图看不见的细节不要猜。品牌、Logo、可读文字和精确地点转为普通颜色、形状、材质与空间描述。

## A—H 同系延伸

- 父图的上装、下装、外层、鞋、包、配饰和固定道具组成不可拆的完整穿搭；除非用户明确说“换装延伸”，八条之间不得换衣服。
- A：完整全身，看清头、双脚、支撑点和环境关系。
- B：三分之二或半身，但保留父姿势证据；坐姿要看见膝、座面、栏杆或支撑手。
- C：只做一个兼容的高机位或低机位变化，不同时更换景别与动作。
- D：相机移到约 30—45 度侧向或斜侧，父动作与镜头距离不变。
- E：相邻重心与肢体几何，写清新的支撑脚、膝、髋或手臂轮廓。
- F：只使用父图已有道具或场景支撑物，加入手部任务、注意力和相邻表情。
- G：进入新姿态的过渡状态，例如正在起身、落座、跨步、回身或靠向已有支撑物。
- H：新姿态完成后的　定状态，继续保留父地点、穿搭、固定道具、主光线和媒介。
- 每条都是可单独复制的完整英文 Prompt，不能让用户自行拼接固定底盘。

## 组合语法

### `31模特在36环境`

- 31 锁定人物外貌类型或 Soul ID、妆发、完整穿搭、表情、Pose、受力、手部任务、道具、景别、机位、构图与主摄影质感。
- 36 只替换地点、背景结构、季节天气和环境亮度，不带入36的人物、服装、动作、表情或机位。
- 两卡光线冲突时保留人物卡的主摄影关系，让环境卡只贡献可见的背景亮度与反射证据。

### `脸1＋环境3＋穿搭8`

- 脸1：只负责外貌类型、妆发和气质；模式 B 时始终改用当前 Soul ID。
- 环境3：负责地点、Pose、受力、注意力、机位、光线和媒介。
- 穿搭8：完整负责上装、下装、外层、鞋、包、配饰与固定道具，不拆单品。
- 先检查季节、裸露程度、鞋履动作、衣物遮挡、道具接触、色彩和摄影兼容性；冲突时做最小调整，不引入第四张图。

## 用户服装图或场景图

- 用户附服装图＋编号：编号母图继续主导人物状态、Pose、构图、光线和媒介；参考图只低权重替换服装模块。Prompt 信息量约 70%—80% 写母图，20%—30% 写参考服装。
- 完整造型图只提取轮廓、层次、材质、配色、鞋包与配饰；商品模特身份、姿势和棚拍背景不参与。单品图只替换可见单品。
- 用户附场景图＋编号：参考图只提取空间类型、两个最强结构锚点、墙地材质、天气和环境光；不继承其中人物、服装、Pose、机位或媒介。
- 参考图与父姿态冲突时先说明，再做最小位置修正；不要让外部衣服或场景压过母图的生命力与构图。

## 活人感质量门槛

每条 Prompt 必须有：一个微事件、一个明确注意力对象、真实支撑与手部任务、人物对风 / 阳光 / 人流 / 道具 / 空间的反馈、一套兼容的机位透视，以及最多两项抓拍痕迹。生命力不等于统一大笑、跳跃或直闪；冷感、安静、疲惫、专注和松弛也要通过事件与真实受力表现。

服装要搭配合理。用户只说“牛仔、皮革、针织”等材质时，默认只放在一件主单品上，不扩散到全身；鞋履必须支持动作，外套、包和道具不能遮断关键支撑。

一条 Prompt 只选一个主摄影媒介。近距离广角、观察式长焦、鱼眼、自然光、逆光与直闪必须忠于母图，不能自由混搭。保留真实皮肤、自然褶皱、准确肢体、可信手部和道具接触。

## 输出格式

首轮：`生成设置 → 01—08中文方向 → 数据来源编号 → 完整英文 Prompt`。

单编号：先 `00｜母图复现提示词（由成图反推）`，再 `编号-A` 至 `编号-H`。组合请求先用中文写清每个编号只负责哪个模块，再给完整英文 Prompt。
