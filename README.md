# 服装 AI 街拍 Skills

面向服装电商和穿搭创作者的通用出图方法：按衣选人、丰富表情、整理人物参考、套用街拍底图换装、核对细节，再复用到下一款商品。按所选工具的图片参考与编辑能力使用。

## 先从这里开始

- [下载完整资料包](服装AI街拍-Skills资料包.zip?raw=true)
- [查看使用说明](开始使用.md)
- [直接看每一步的完整提示词](skills/clothing-street-photo-workflow/references/step-prompts.md)

支持 Skill 的助手可按自己的导入方式安装独立技能包；普通生图网页或应用也可直接复制提示词并提供对应图片。

| 48 张街拍母图与原作者规则 | [图库 Skill](skills/soul2-candid-street-prompting/SKILL.md) | [ZIP](导入包/soul2-candid-street-prompting.zip?raw=true) |

主流程可独立使用，两个参考库按需选用。人物主图负责长相，商品图负责款式，底图负责动作、构图和现场光线；工具有原生人物功能时可以复用，没有时使用实际图片参考。

完整提示词包含单图与可选双参考的人脸表情扩展、按需转头方向纠偏、单品与上下装两件套换装、旧图复用及局部修整。已有满意人物或底图时，从需要的步骤继续。

## 简短使用示例

> 图1是街拍底图，图2是人物主图，图3是商品图。沿用底图的动作、构图和光线，换成这个人物并穿上这件衣服，生成1张供我核对。

> 沿用之前确认的人物参考和底图，换上这次的新款商品。只修改指定衣物，展示结果供我对照检查。
