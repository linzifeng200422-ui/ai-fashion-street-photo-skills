## 名称核对

本版本统一写 **Higgsfield Soul 2.0（Soul V2）**。官网同一介绍页使用这两种写法，指同一个生图模型；`suol` 为拼写错误。**Soul ID** 是人物身份复用功能，不能当成另一个生图模型。见[官方介绍](https://higgsfield.ai/soul-intro)。

## 路线概览

| 维度 | 通用路线 A（已有底图） | 原教程路线 B（教程复现） |
|---|---|---|
| **适用场景** | 已有实拍底图或街拍图库，跨任意生图工具 | 无现成底图，需完整复刻原教程工作流 |
| **模特选定** | 任意工具生成候选 / 沿用已有模特图 | Higgsfield / Soul 2.0 选模（01:32） |
| **表情扩展** | 各张独立参考主图生成多角度近景 | GPT ImageGen（01:51，不绑定特定版本） |
| **底图准备** | **只选已有图**，裁切单张，不启动生成 | **Soul 2.0 候选生成**（02:54）→ 人工质检后选定单张；已有合格底图可跳过 |
| **换装执行** | 当前可用图生图 / 图像编辑工具 | Codex ＋ 实际可用图像编辑工具（03:28） |
| **细节修整** | 当前可用局部编辑工具 | 局部重绘 / 必要时 Photoshop 精修（04:25） |

## 注意事项

1. **纯静态图片工作流**：专注于服装电商静态街拍展示图，不包含视频生成。
2. **角色引用真实性**：若平台支持角色库（如 Soul ID），需经真实创建或已有引用才可调用，不虚构“已训练”或“永久记忆”状态；无角色库时直接使用普通图片参考。
3. **底图生成约束**：生成街拍底图时应表达单一连贯动作，避免在同一画面中叠加互斥行为（如不可同时骑车又抱臂）；焦段与镜头距离属于文字摄影设定。
4. **人工品控**：所有出图须与商品原图及人物主图严格核验，尤其注意复杂印花、文字字形与光影自然衔接。
