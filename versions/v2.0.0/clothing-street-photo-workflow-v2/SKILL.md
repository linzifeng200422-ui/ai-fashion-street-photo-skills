# 服装街拍出图流程 (v2.0.0)

用于组织人物身份参考、商品图和拍摄底图，完成高质量的静态服装电商展示图与街拍图输出（不包含动态视频生成）。流程可直接执行生图，也可仅输出对应阶段的提示词；不强制绑定特定生成器或角色库。

## 路线与平台选择

- **用户已选平台优先**：沿用该平台及真实可用模型。用户同时要求“借鉴原教程”时，只迁移相应方法，不自动切到 Higgsfield、GPT 或另一服务。若在其他工具生成新底图，可借用路线 B 的写词与选片方法，明确这是平台适配，不称作已启用 Soul ID。
- **通用路线 A**：保留已有底图的挑选、人物与商品参考编辑流程，见分步提示词手册。
- **原教程路线 B**：用户选择原教程平台组合时，按原片展示的平台分工执行；无底图时补入“生成街拍候选→核验→选定单张”。平台对应关系和未披露型号见原教程平台说明。
- 已明确的选择直接复用，不为内部选路重复询问；只有平台、人物来源、费用或执行范围确有关键缺项时才问。

正式产品名为 **Soul 2.0**，官网亦称 **Soul V2**；本 Skill 统一使用前者。Soul ID 是身份复用功能，二者分开标注。

## 从已有材料继续

- **已有人物参考和底图**：直接进入换装，不重新选模或补充表情。
- **已有选定主图**：按需补充必要表情与角度，或直接将该图作为人物参考。
- **尚无人物**：结合服装展示风格生成虚构模特候选，选定后锁定为主图。
- **已有满意成图**：针对存在问题的局部做修整，不推翻整张重新生成。
- **下一款上新**：沿用已有模特参考与拍摄底图，只替换商品图。

> **示例边界提示**：教程演示中的女性模特、短发、CCD直闪、4位候选或6张表情均为演示示例，切勿作为通用硬性规则限制用户需求。年龄、性别、发型、画幅、张数与摄影风格均以当前实际需求为准。已提供的信息直接使用，仅在影响核心出图效果的关键参数缺失时进行必要确认。

## 人物参考的两种用法

“人物1”是对当前选定模特及其身份图片的便捷统称，不代表底层工具必定存在对应的角色对象实体。

1. **普通图片参考（通用推荐）**：保存选定的主图与合格表情图，出图时以图片形式传入，或引用当前对话中工具可访问的素材。不需要预先创建角色库；只要图片能正常访问，无需反复手动上传。
2. **工具自带角色引用（原教程/特定平台）**：仅在所选工具确实支持原生角色库（如 Soul ID）且当前已存在已建好的角色时沿用。严禁虚构“已训练成功”、“已绑定”或“永久记住”；若用户指定的角色尚未就绪，明确标为待完成，可先准备后续提示词；核验真实可用后再调用。仅在用户未要求真实 Soul ID，或明确接受普通图片替代时采用图片方式，并说明这不等于 Soul ID。

无论哪种方式，均以确认且清楚的人物图为根本依据。依据本次实际上传的附件清晰注明各图职责；使用角色引用替代主图后，其他附件编号依次前移调整。

## 工作方法（核心七步）

1. **按衣选人**：依据服装品类与展示风格明确人设要求。可使用纯文字描述或辅助风格参考选定单张满意人像作为主图；已有模特时直接沿用。
2. **补充表情与角度**：以选定主图为唯一身份基准，按本次需要扩展不同表情与视角。**各张独立参考同一主图**，不默认用上一张新结果继续衍生；修某一张时可正常编辑该张，并保留身份依据。
3. **整理人物参考**：人工核对长相一致性、眼神与微表情自然度，以及本次所需角度是否齐全。明确主图负责主要五官身份，补充图提供视角依据。
4. **准备拍摄底图**：
   - *通用路线 A*：从自备照片、已有实拍或图库中挑选合适单张底图，裁出所需画面，不启动文本生成。
   - *原教程路线 B*：在无合适底图时，使用提示词生成街拍候选底图池（详见 [原教程平台说明](references/tutorial-platforms.md)），经人工质检（长相一致/服装可读/姿态光影合格）后选定单张底图；已有底图时同样直接跳过生成。
5. **指定商品换装**：
   - 底图决定身体动作、画面构图、机位视角与环境现场光。
   - 人物参考决定五官与外貌，换入人物的受光与阴影必须融入底图环境，严禁照搬人像参考图的背景与布光。
   - 商品图决定具体款式、颜色、版型与可见细节。**只更换指定商品**，其余未指定衣物、鞋靴与配饰严格保留；上下装分别对应，避免材质混淆。底图本身已是目标模特时无需重复改脸。
6. **对照与局部修整**：比对商品图与人物主图，仔细检查五官、款式、颜色、字母印花、边缘羽化与接触阴影。修图时明确指出“具体位置＋错误现象＋对应参考”，修后必须同步回查整张画面的其他区域是否发生非预期变动。
7. **上新复用**：沉淀选定的人物素材、满意底图与有效提示词模板。后续上新仅替换商品图并微调光影衔接，不重复前端选人与底图搜寻工作。

## 严格责任分工

- **底图**：换装时提供人物动作、取景机位、构图与现场光线。
- **人物参考**：提供五官长相与特征，其面部受光与阴影必须适应底图现场。
- **商品图**：提供所指定衣物的款式、色彩、剪裁与可见工艺细节。
- **摄影参考**：可选辅助输入，仅提供主光方向与胶片/数码成像质感，绝不借用其人物长相与服装。

## 交付与执行边界

根据当前环境工具实际支持的图片输入数量、局部蒙版及编辑能力调整指令，不生搬硬套特定平台的专属语法。若当前工具缺少某项能力，应明确说明其技术边界并提供替代方案，严禁捏造不存在的功能。仅在用户要求执行生成时调用相应工具；若仅要求准备提示词，则只交付标准化提示词方案，不擅自启动生成。所有生成结果均以实际画面与严谨核验为准，不承诺“百分之百绝对不变脸”或“完全免修”。
