## 名称和当前输入模式

2026-10-19 核对[官方介绍](https://higgsfield.ai/soul-intro)：正式名称是 **Soul 2.0**，同页也使用 **Soul V2**，指同一个模型；`suol` 为拼写错误。**Soul ID** 是人物身份复用功能，不是另一个生图模型。

[官方 Soul 使用说明](https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-use-soul-to-generate-images)将 Soul ID、Soul Reference 和文字提示词区分开：其当前说明是，附上普通参考图时提示词栏不可用，仍可配合 Soul ID 与色彩功能。因此，不能假定把人物普通照片附上，再粘贴下方文字，就等于按原教程启用了 Soul ID。执行前核对当前页面输入模式；原教程“文字提示词＋实际选定 Soul ID”与普通图片替代不是同一个输入方式。

用户选择 Flova 或其他平台时，沿用其真实支持的参考与编辑方式，不照搬 Higgsfield 的角色名、附件编号或按钮，不自动跨服务。这里不预设任何订阅价格、积分、可用模型或训练门槛。

## 没有底图时：原教程方法的可复制模板

下方是按教程摄影方法整理的新模板，不冒充作者原始提示词。先确认平台中实际选定的人物与输入模式；未就绪时可先准备文字，不提交生成。

```text
使用当前实际选定的[人物/Soul ID]，保持其已确认的长相、发型和年龄呈现。人物名称只用于说明，执行时须真实选中相应角色；不得把写出名称当成已绑定身份。

摄影师从[距离]、[观察方向与机位高度]，用[焦段观感]拍摄[全身/七分身/其他景别]。人物正在[一个连贯事件]，重心落在[支撑点]，双手分别[自然任务]，目光看向[明确对象]，呈现[与情境一致的反应]。

地点为[具体街景]，前中后景由[可见空间结构]形成。主光来自[光源及方向]，人物受光面、阴影和地面接触影符合该光线；成像采用[本次选定的摄影媒介和质感]。

让身体比例、手脚与道具接触合理，衣服主要展示区域清楚，保留自然衣褶和适合当前景别的皮肤细节。输出独立照片，不做拼图，不加排版文字。
```

- 按实际平台参数栏设置本轮数量、画幅和清晰度；只在提示词中写参数不代表界面已设置。原片 3:4、2K 是示例。
- “六到八米”“长焦”“轻微 CCD”是教程示例的文字摄影设定，不是界面独立数值滑块，也不强制用于夜景、直闪或其他风格。
- 每张图描述相互兼容的动作与情绪。可以是复合但连贯的事件，如推车回看；避免把互斥状态塞进一张图，如同时骑车又双手抱臂。这是本项目的执行整理，不冒充作者额外声明。
- 候选不合格时，保留满意部分，只针对身份、服装可读性、姿态或光影缺项调整；合格后选定单张再换装。原片没有证明固定成功率或免修。

## 换装与局部修整

换装仍使用[通用分步提示词](step-prompts.md)的附件职责：底图管动作构图与现场光，人物图管身份，商品图管指定款式；人物受光适应底图。底图已是目标人物时不重复换脸。附件增减后重新编号，整套商品分别标明上装和下装。

修整写明“具体位置＋具体差异＋对应参考”，未指定区域尽量保留，修后回查其他区域。工具是否支持蒙版、局部重绘或普通参考图，以实际能力为准；必要时采用作者提出的 Photoshop 人工精修路径，不假称原片展示了自动修复或已完成 Photoshop 操作。
