# 服装街拍 v2.0.0：平台选择与提示词流程

图中 A 表示通用已有底图路线，B 表示原教学视频展示的平台组合。**用户已指定平台时优先沿用该平台**；借用原教程方法，不等于自动换服务或已启用 Soul ID。Soul 2.0 与 Soul V2 为同一模型名称写法。

```mermaid
flowchart TB
    START["本轮需求与已有素材<br/>所选平台优先；确定数量、画幅和修改范围<br/>仅要提示词时，不启动生成"]
    START -->|"没有人物"| P1
    START -->|"已有主图，需要补图"| P2
    START -->|"人物参考已够用"| P3
    START -->|"人物与底图齐全"| P5
    START -->|"仅需局修"| FIX

    P1["① 按衣选人，选定主图<br/>A：用户选定的生图工具<br/>B：Higgsfield / Soul 2.0<br/>写服装风格、气质、景别、光源与落影<br/>候选要有差异；避免磨皮和重复假纹理"]
    P1 -->|"按需补表情与角度"| P2
    P1 -->|"主图够用"| P3
    P2["② 表情与角度扩展<br/>A：所选工具；B：GPT 图像生成，版本未公开<br/>每张独立参考同一主图，不默认逐张串改<br/>写具体反应、眼眉嘴角联动与转头方向<br/>摄影参考只管摄影表现，不带入其身份"]
    P2 --> FACE{"同人、表情与<br/>所需角度合格？"}
    FACE -->|"不足，只补缺项"| P2
    FACE -->|"合格"| P3

    P3["③ 整理身份参考，不生成新图<br/>主图和补充图分别标明用途<br/>普通图片须实际传入或可访问<br/>原教程使用真实 Soul ID；不假称已训练"]
    P3 --> ID{"本轮明确采用 Soul ID？"}
    ID -->|"否"| PIC["采用所选工具实际支持的图片参考<br/>不把普通图片称为 Soul ID"]
    ID -->|"是"| READY{"真实角色已就绪？"}
    READY -->|"是"| ROLE["Higgsfield：实际选择对应 Soul ID<br/>角色名称只是说明，不替代真实绑定"]
    READY -->|"否"| WAIT["标为待完成，先准备后续提示词<br/>完成并核验真实角色后再使用"]
    WAIT -->|"角色核验可用"| ROLE
    WAIT -->|"用户明确接受图片替代"| PIC
    ROLE --> BASE
    PIC --> BASE

    BASE{"已有合格单张底图？"}
    BASE -->|"是"| P5
    BASE -->|"尚未选定"| ROUTE{"底图准备方式"}
    ROUTE -->|"A：选择已有素材"| A4["④A 选择已有底图<br/>自备实拍、已有生成图或有权使用的图库<br/>只选图，不生成；拼版先裁成单张<br/>检查衣服可读、姿势合适、光线符合需求"]
    ROUTE -->|"B：原教程生成候选"| B4["④B 生成街拍候选<br/>原平台：Higgsfield / Soul 2.0；原片使用 Soul ID<br/>写机位景别、连贯动作、环境光线与摄影质感<br/>距离、焦段、CCD 是文字设定；数量画幅另核对<br/>其他平台适配按其真实输入能力，不伪称 Soul ID"]
    A4 --> P5
    B4 --> QC{"同人、姿势、光影和<br/>服装展示合格？"}
    QC -->|"不足，针对缺项调整"| B4
    QC -->|"合格，选定单张"| P5

    P5["⑤ 换脸与换装<br/>A：所选编辑工具<br/>B：Codex 串联＋实际图像编辑工具，后台型号未公开<br/>底图管动作机位与现场光；人物图管身份<br/>商品图管指定款式，上下装分别编号<br/>只换指定衣物；已是目标人物时不换脸"]
    P5 --> P6["⑥ 对照人物与商品原图核验<br/>检查长相、款式、颜色、字形、边缘和光影<br/>人物受光服从底图，不搬入人像背景或布光"]
    P6 --> PASS{"结果合格？"}
    PASS -->|"否"| FIX["局部修整：可用编辑工具，必要时 Photoshop<br/>写具体位置＋差异＋对应参考<br/>未指定区域尽量保留，修后回查全图<br/>原片只建议 PS 精修，未展示具体操作"]
    FIX --> P6
    PASS -->|"是"| P7["⑦ 保存复用<br/>保留人物图、底图、有效提示词与可用引用<br/>下一款只更新商品和确需改变的要求"]
    P7 -->|"下一款商品"| P5
```
